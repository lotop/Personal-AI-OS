## Objective

把当前散布于 System、Factory、Harness、Deployment 与 Skills 中的 `WORKING` 资产整理为六个可独立确认的 Approval Pack，为 V1.2.0 Stable 建立没有未决 Canonical 内容的批准基线。

## Scope

1. Governance + Security Pack
2. Mode + Memory + Session Pack
3. Factory + Templates Pack
4. Harness + Hooks Pack
5. Deployment + Recovery Pack
6. Skills Pack

## Excluded

- 本审计不自动批准任何文件，不执行 Canonical Promotion。
- 不把动态 Registry、项目内 Working 状态或模板中的合法默认状态误判为系统未完成。
- 不处理 Dashboard、公开发行包构建器、Feedback Pipeline 或 Upgrade Engine。

## Read Set

- `00_system/`、`01_templates/`、`02_registry/`
- `03_adapters/`、`04_project_factory/`、`05_harness/`、`06_deployment/`
- `.agents/skills/`
- 当前 Schema、Decision、Release Evidence 与历史批准记录

## Write Set

- 本 Audit 文档
- 后续六个 Approval Pack Review 文档
- `02_registry/tasks.toml`

## Expected Output

- 每个相关文件都有 `APPROVE / ARCHIVE / GENERATED_OR_LOCAL / KEEP_RUNTIME_WORKING / FIX_BEFORE_APPROVAL` 处置建议。
- 每个 Approval Pack 单独列出用途、层级、维护者、Source-of-Truth 属性、依赖、风险、Diff 与确认项。
- Founder 按模块确认；确认前不改变 Canonical Authority。

## Acceptance Criteria

- 64 个已发现的 `WORKING` 标记全部完成语义分类。
- 六个 Pack 文件集合不重叠且无遗漏。
- 合法 Runtime/Project Working 与未批准 Canonical Working 明确分离。
- 输出首个可供 Founder 确认的 Module Approval Pack。
