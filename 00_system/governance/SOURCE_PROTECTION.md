# Source Protection

> 状态：`APPROVED`
>
> Canonical Authority：`FOUNDER_APPROVED`（`PAOS-016`）

- Original Source 默认只读，并保留来源、日期、Owner 和校验和。
- 转换、摘要、OCR、翻译和提取结果属于 Derived Working，不覆盖 Source。
- Source 内容错误时，以补充说明或新版本纠正，不静默改写历史证据。
- 外部 URL、聊天和云端附件应记录获取时间及可用性，不假定长期可访问。
- Source 进入 Archive 时仍保留 Provenance；删除必须有批准、保留期和恢复记录。
